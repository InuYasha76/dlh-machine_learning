# Machine Learning

Repository containing projects and exercises covering foundational and advanced machine learning topics, including mathematics, data pipelines, and unsupervised learning.

## Repository Structure

- `math/`: Mathematical foundations of machine learning (Linear Algebra, Calculus, Probability, Plotting)
- `pipeline/`: Data engineering and learning pipelines
  - `databases/`: Database operations and integrations
  - `pandas/`: Data manipulation with Pandas
  - `unsupervised_learning/`: Unsupervised learning techniques (clustering, dimensionality reduction)

## Environment & Setup

- Python 3.9
- Virtual environment: `.venv`
- Requirements: see `requirements.txt`
